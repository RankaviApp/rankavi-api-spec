# Rankavi API Spec

OpenAPI 3.1 specification and integration docs for the [Rankavi](https://rankavi.com) brand mentions API.

Rankavi places real, unlinked brand mentions on relevant websites, helping brands get cited by name in AI answer engines like ChatGPT, Perplexity, and Google AI Overviews.

- Spec: [`reference/openapi.yaml`](reference/openapi.yaml)
- Docs: [`docs/`](docs/)
- Full API documentation: [app.rankavi.com/api-docs](https://app.rankavi.com/api-docs)
